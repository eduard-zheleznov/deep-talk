# DeepTalk - Программа "Глубокое Познание Себя"

## Описание проекта
DeepTalk - многопользовательская платформа для глубоких разговоров. Пользователи создают группы, приглашают друзей и обсуждают вопросы из разных категорий для самопознания.

## Технологический стек
- **Frontend:** React + TailwindCSS + Shadcn/UI
- **Backend:** FastAPI + Python
- **Database:** MongoDB
- **Auth:** JWT tokens

## API Endpoints
- `POST /api/auth/register` - регистрация
- `POST /api/auth/login` - вход
- `GET /api/profile` - получить профиль
- `PUT /api/profile` - обновить профиль
- `GET /api/groups` - список групп
- `POST /api/groups` - создать группу
- `POST /api/groups/{id}/invite` - создать приглашение
- `POST /api/groups/join/{code}` - присоединиться
- `GET /api/questions/next/{groupId}` - следующий вопрос
- `POST /api/questions/{id}/mark` - отметить вопрос
